# CB UI 介绍

CB UI 是一套基于 **TDesign** 二次开发的前端组件库，使用 **Vue 3 + TypeScript** 构建，搭配 **VitePress + TailwindCSS + Sass** 搭建文档站点。

::: tip 核心定位
CB UI 不是从零开发的组件库，而是基于 TDesign 进行二次封装，提供统一的命名规范、样式主题和团队使用习惯。
:::

---

## 一、核心特性

- **基于 TDesign 二次开发**：底层使用 `tdesign-vue-next`，稳定可靠
- **Vue 3 组合式 API**：基于 Composition API 构建，逻辑复用更灵活
- **TypeScript 编写**：完整的类型定义，IDE 智能提示
- **TailwindCSS + Sass**：原子类快速开发，Sass 管理主题变量
- **复制即用**：组件代码可直接复制到项目，无需 npm 发布

## 五、为什么基于 TDesign 二次开发？

| 优势 | 说明 |
|---|---|
| 稳定可靠 | TDesign 是腾讯开源的企业级设计系统，经过大规模业务验证 |
| 组件丰富 | 提供 60+ 基础组件，覆盖大部分业务场景 |
| 设计规范 | 遵循统一的设计规范，减少设计决策成本 |
| 按需定制 | 二次封装后可以针对团队习惯调整 API |

---

## 六、为什么不发布 npm 包？

| 原因 | 说明 |
|---|---|
| 内部使用 | 主要供个人/团队内部使用，无公开发布需求 |
| 灵活定制 | 不同项目可能有不同的定制需求，复制代码更灵活 |
| 版本控制 | 避免 npm 包版本管理复杂性 |
| 即时修改 | 复制到项目后可直接修改，无需等待发布更新 |

## 八、项目结构

```

├── packages/
│   ├── components/     # 组件库源码（基于 TDesign 二次封装）
│   ├── theme/          # 主题与样式变量
```
