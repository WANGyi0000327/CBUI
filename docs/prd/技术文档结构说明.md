## 四、使用文档编写规范

### 4.1 快速上手指南

```markdown
---
title: 快速上手
---

# 快速上手

## 安装

\`\`\`bash
npm install @cb-ui/components
\`\`\`

## 引入方式

### 全量引入
\`\`\`ts
import CBUI from '@cb-ui/components'
import '@cb-ui/components/dist/style.css'

app.use(CBUI)
\`\`\`

### 按需引入
\`\`\`ts
import { Button } from '@cb-ui/components'
import '@cb-ui/components/button/style.css'
\`\`\`

## 按需加载（推荐）
- 配合 unplugin-vue-components 自动导入
```

### 4.2 组件使用文档

```markdown
---
title: Button 按钮
---

# Button 按钮

常用的操作按钮。

## 基础用法

<DemoBlock>
  <template #default>
    <cb-button>默认按钮</cb-button>
    <cb-button type="primary">主要按钮</cb-button>
  </template>
  <template #code>
    \`\`\`vue
    <cb-button>默认按钮</cb-button>
    <cb-button type="primary">主要按钮</cb-button>
    \`\`\`
  </template>
</DemoBlock>

## API

### Props

| 属性 | 说明 | 类型 | 默认值 |
|---|---|---|---|
| type | 按钮类型 | `Button.Type` | `'default'` |
```
