## 一、项目背景与目标

### 1.1 项目背景

随着业务系统复杂度提升，团队沉淀了大量可复用的前端组件。当前组件散落在各项目中，缺乏统一管理、版本控制和文档说明，导致：

- 组件重复开发，维护成本高
- 新成员上手困难，缺少可视化示例
- 设计规范不统一，UI 一致性差
- 组件使用方式依赖口头传播，知识沉淀不足

### 1.2 项目目标（现状达成情况）

| 目标         | 原定衡量指标                       | 现状                                                    |
| ------------ | ---------------------------------- | ------------------------------------------------------- |
| 组件统一管理 | 核心基础组件覆盖率达 80%           | ✅ 组件库已沉淀 **44 个组件**，全量入口脚本自动维护     |
| 开发效率提升 | 组件复用率提升 40%                 | ✅ `pnpm gen` 脚手架 + 新组件开发文档，添加组件免问作者 |
| 文档质量     | 每个组件提供 API + 示例 + 最佳实践 | ✅ 44 个组件有文档（含 DemoBlock 可交互示例），1 个待补 |
| 设计一致性   | 统一设计 token，UI 视觉一致性 90%  | ✅ `@cb-ui/theme` 统一变量 + TDesign 主题定制           |

## 三、功能需求

### 3.1 文档站整体结构（现状）

```
┌─────────────────────────────────────────────────────────────┐
│                     CB UI 文档站（VitePress）                  │
├─────────────────────────────────────────────────────────────┤
│  顶部导航：指南 │ 组件 │ PRD                                    │
├─────────────────────────────────────────────────────────────┤
│  指南侧边栏          组件侧边栏              PRD 侧边栏        │
│  ├─ 介绍             ├─ 基础组件               ├─ 组件库文档站PRD │
│  ├─ 快速上手         │   ├─ 按钮与操作         ├─ 技术选型方案    │
│  ├─ 新组件开发       │   ├─ 输入与选择         ├─ Props提取与     │

└─────────────────────────────────────────────────────────────┘
```

### 3.2 功能清单（现状 vs 规划）

#### 3.2.1 已实现功能

| 模块       | 功能点                | 说明                                                         |
| ---------- | --------------------- | ------------------------------------------------------------ |
| 导航       | 指南 / 组件 / PRD     | 三入口导航，侧边栏自动生成                                   |
| 组件侧边栏 | 三分类自动归类        | `config.ts` 按三集合归类；未登记组件自动进「未分组」兜底显示 |
| 组件文档页 | 标题 + 基础用法 + API | DemoBlock 可交互示例 + Props/Events/Slots 表格               |
| 代码示例   | 可复制代码块          | DemoBlock `#code` 插槽内展示 Vue SFC 源码                    |
| 搜索       | 本地全文搜索          | VitePress local search                                       |
| 脚手架     | `pnpm gen`            | 生成组件 5 件套 + 文档模板 + 自动更新入口                    |
| 入口维护   | `pnpm gen:index`      | 扫描组件目录自动重写 `src/index.ts`                          |
| API 草稿   | `pnpm extract:props`  | 从 types.ts 提取 API 表格草稿到 `docs/.vitepress/generated/` |
| 指南文档   | 5 篇                  | 介绍 / 快速上手 / 新组件开发 / 组件开发指南 / 常见问题       |

#### 3.2.2 组件详情页规范（现状）

每个组件文档页面包含：

| 区块     | 内容                   | 现状说明                                         |
| -------- | ---------------------- | ------------------------------------------------ |
| 组件标题 | 组件名称 + 简介        | frontmatter `title`，侧边栏同步读取              |
| 基础用法 | 可交互示例             | `<DemoBlock>` 包裹真实组件                       |
| 代码示例 | 可复制的代码           | DemoBlock `#code` 插槽（注意禁止嵌套代码块标记） |
| API 文档 | Props / Events / Slots | 表格形式，由 types.ts JSDoc 辅助生成             |

#### 3.2.3 规划功能（未实施）

| 功能     | 描述               | 优先级 |
| -------- | ------------------ | ------ |
| 多语言   | 支持中文/英文切换  | P2     |
| 主题预览 | 组件库主题定制演示 | P1     |
| 版本历史 | 组件变更日志页     | P1     |

## 五、技术约束（现状）

### 5.1 技术选型（实际锁定版本）

| 层级     | 技术栈             | 实际版本（pnpm-lock）            |
| -------- | ------------------ | -------------------------------- |
| 组件实现 | Vue 3 + TypeScript | Vue 3.5.40 / TS 5.9.3            |
| 底层组件 | TDesign            | tdesign-vue-next 1.20.5          |
| 文档站点 | VitePress          | 1.6.4                            |
| 组件构建 | Vite               | 8.1.5（+ vite-plugin-dts 4.5.4） |
| 文档构建 | Vite               | 5.4.21（VitePress 内置）         |
| 原子样式 | TailwindCSS        | 3.4.19（文档站）                 |
| 复杂样式 | Sass               | 1.101.3（modern-compiler）       |
| 包管理   | pnpm               | 9.x（workspace）                 |
| 单元测试 | Vitest + happy-dom | 3.2.7                            |

### 5.2 代码规范（现状）

- ESLint + Prettier 统一风格；`.eslintrc.cjs` 对 `*.cjs` 脚本关闭 no-require-imports
- 组件必须有 `types.ts`（Props/Emits/Slots 三接口 + JSDoc）
- 组件命名统一 `Cb` 前缀 + kebab-case 目录（详见《组件开发指南》）
